---

## Зачем

Координатор уже умеет спросить в чате, когда сам `.coordinator` отстал от `origin/main` (`sessionStart` → `update_check.py`). Тот же жест нужен для зависимостей продукта: раз в неделю (или по своему интервалу) на пульсе появляется карточка, агент видит её и спрашивает: «проверить и обновить?»

Человек решает. Пока нет «да» — никто не трогает `go.mod` и не открывает hotfix.

---

## Что это не есть

| Не путать | Почему |
|-----------|--------|
| Слот задачи (`tasks[]`) | Слот держит репозиторий. Карточка «проверить whatsmeow» **не** занимает BotWhatsAppMD и **не** участвует в `parallel.mdc`. |
| Ресёрч | Ресёрч привязан к вкладке и закрывается. Автоматизация живёт в каталоге, пока её не выключат. |
| Cursor Automation / `/loop` | Отдельный процесс IDE, пульс его не видит. |
| Dependabot / тихий `pre-push` | PR или bump без вопроса Отто. |

Пока человек не согласился, это **оверлей пульса**, не claim.

Согласие «да, обнови» → обычный hotfix на нужном сервисе, с параллельной проверкой **в тот момент**. Если сервис уже держит другой слот — стоп, как всегда.

---

## Два процесса

| Кто | Когда живёт | Роль |
|-----|-------------|------|
| Хуки Cursor (`sessionStart`) | Пока открыт Cursor | Единственный канал **вопроса в чат**. Уже зовёт `session_notice()`. |
| API Координатора (`backend.sh`) | Пока открыт дашборд | Рисует пульс. Может дописать due в кэш, если хук ещё не сработал. |

Часы автоматизации — **кэш на диске** (`Common/data/.cache/…`, gitignore). Хук и API читают одно и то же. Дашборд не обязателен, чтобы спросить в чате. Хук не обязателен, чтобы увидеть карточку на [Coordinator](http://localhost:5175), если API недавно прогнал проверку.

Не строить отдельный демон «ради недели».

## Каталог

Файл в git: `Common/data/settings/automations.json`.

Не в `.current_task_*`. Не в jsonl как вечная «задача». Состояние прогона — только кэш.

Черновик схемы (имена полей можно уточнить в коде, смысл — нет):

```json
{
  "version": 1,
  "items": [
    {
      "id": "coordinator-self",
      "kind": "git_behind",
      "title": "Обновление Координатора",
      "repo": ".coordinator",
      "interval": "1d",
      "enabled": true
    },
    {
      "id": "whatsmeow",
      "kind": "go_module",
      "title": "whatsmeow",
      "repo": "BotWhatsAppMD",
      "module": "go.mau.fi/whatsmeow",
      "interval": "7d",
      "enabled": true
    }
  ]
}
```

`kind` — как проверять. Первый срез: `git_behind` (уже есть) и `go_module` (`go list -m …@latest` vs текущий). Новые kind — отдельные срезы, каталог тот же.

Выключить пункт = `enabled: false`, не удалять id (кэш и журнал ссылаются на id).

## Состояния пункта

Не статус слота. Локальный кэш по `id`:

| Состояние | Пульс | Чат |
|-----------|-------|-----|
| `idle` | в каталоге, без карточки due | молчит |
| `due` | карточка «пора проверить» | на следующем `sessionStart` Отто спрашивает **один раз за цикл** |
| `snoozed` | в каталоге, next_due сдвинут | молчит до next_due |
| `running` | бейдж «человек согласился, идёт hotfix» | не дублировать вопрос; due снимается, когда hotfix закрыт или человек сказал «не сейчас» |

Спам: не на каждый `afterAgentResponse`. Только `sessionStart` (как сейчас у self-update), и только если цикл ещё не спрашивали.

«Нет» / «потом» → `snoozed` на тот же `interval` (для недели — +7 суток). Не отдельный слот.

«Да» → агент открывает hotfix (`FIX-…`) на `repo` из каталога, `related_docs` на этот документ. Кэш: `running` + `accepted_task_id`. После `task_completed` этого фикса — прогон записан, next_due = now + interval, снова `idle`.

Если после проверки обновлять нечего — тоже idle + next_due, без hotfix. В чате одна фраза Отто: «whatsmeow уже последний, следующий чек через неделю».

## UI

Сейчас таблица слотов живёт в **Stats** и дублируется на обзоре. Отдельной секции «Задачи» в сайдбаре нет.

Согласованно:

1. **Stats** — вкладки у блока задач: **Слоты** (текущая `TaskTable`) и **Автоматизации** (каталог: id, интервал, last/next, enabled, due).
2. **Обзор / Pulse** — карточка только когда пункт `due` или `running`. Рядом с ресёрчем, **не** в `tasks[]` человека. Бейдж вроде «Автоматизация», не «В работе».
3. Пятый пункт сайдбара в этом срезе **не** добавляем.

Тексты — `chat_language` / i18n дашборда, как у остальных секций.

## Голос

Отто, коротко, по смыслу пункта. Для whatsmeow:

> Отто: пора проверить whatsmeow (раз в неделю). Проверить и обновить?

Не обновлять до «да». Не `go get` «на всякий случай». Если нужен новый Go (как 1.26) — сказать это **в том же вопросе**, когда проверка уже показала bump.

Правило в `.cursor` в первом срезе не обязательно: хук уже подмешивает `session_notice()` в `additional_context`. Новый абзац в `voice.mdc` — когда свободен слот на `.cursor`.

## Первый пункт: whatsmeow

- Каталог: `whatsmeow`, `interval: 7d`, `BotWhatsAppMD`, модуль `go.mau.fi/whatsmeow`.
- Проверка: сравнить `go list -m` текущий и `@latest`. Сеть и toolchain — fail-open (как self-update): ошибка в кэш, чат не блокировать.
- Согласие → hotfix только на BotWhatsAppMD (и док в Common, если нужно). Не тащить Core «заодно».
- **`BotWhatsAppMD/scripts/pre-push.sh` сейчас сам делает `go get @latest`.** Пока жива автоматизация — pre-push **не** bump'ает: только сообщает, что модуль новее, и гоняет build/тесты. Иначе пульс спрашивает, а push всё равно обновляет молча. Смена хука — отдельный шаг на BotWhatsAppMD (чистый `main`, не этот слот, пока Santé держит Core — WMD свободен).

## Отвергнуто

- Cursor Automation по cron как источник правды.

## Срезы

1. Каталог + обобщить `session_notice()` (self-update = первый item) + кэш due + карточка на пульсе + вкладка в Stats.
2. `kind: go_module` для whatsmeow + вопрос в чате.
3. Pre-push WMD: убрать тихий bump (когда свободен BotWhatsAppMD).
4. По желанию: jsonl, snooze с дашборда, другие модули.

Этот слот (`Services: .coordinator, Common`) закрывает срез 1–2 **после** согласия по документу. Срез 3 — добавление сервиса по `protocol.mdc` §2.2.

---

## Приёмка среза 1–2

- В Stats есть вкладка «Автоматизации», в каталоге видны coordinator-self и whatsmeow.
- Раз в неделю (или с `--force` в утилите) whatsmeow становится due → карточка на обзоре.
- Новый чат Cursor спрашивает проверить и обновить; без «да» `go.mod` не меняется.
- Due-карточка не создаёт слот и не стопает параллельные задачи на BotWhatsAppMD.
- Self-update Координатора ведёт себя как сейчас, только как пункт каталога.
